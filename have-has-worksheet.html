Practice Worksheet: Have / Has

Have I, You, We, They
(Plural / רבים)
Has He, She, It
(Singular / יחיד)
Part 1: Write 'have' or 'has' (השלימי את המילה החסרה)
1. I a red apple in my bag.
2. She beautiful green eyes.
3. The boys a football game today.
4. It a long tail.
5. My teacher a new computer.
Part 2: Circle the correct answer (הקיפי את הנושא המתאים)
1. ( He / I ) has a big dog.
2. ( The cat / The cats ) have milk in the bowl.
3. ( We / She ) have homework.
4. ( You / It ) have a nice smile.
5. ( Dan / Dan and Gal ) has a sister.
Part 3: Order the sentence (סדרי את המילים למשפט נכון)
